# Сборка OBS macOS Capture Filter

[English](build.md) | [Русский](build.ru.md)

В этой инструкции описано, как применить экспериментальную модификацию к OBS Studio 32.0.4 и собрать изменённый плагин захвата экрана для macOS.

> **Экспериментальный проект:** патч успешно применён к чистой копии исходников OBS Studio 32.0.4, а модифицированный плагин `mac-capture` независимо скомпилирован. Проверка работы свежесобранного плагина в отдельном экземпляре OBS пока не проводилась. Полная подготовка окружения на новом Mac также не проверялась.

## Требования

Для сборки понадобятся:

- macOS
- Xcode и Xcode Command Line Tools
- CMake
- Git
- Исходный код OBS Studio 32.0.4
- Зависимости, необходимые для сборки OBS Studio

Модификация использует системный фреймворк Apple ScreenCaptureKit.

Минимальная версия macOS, на которой гарантированно работает модификация, пока не установлена.

## 1. Получение исходного кода OBS Studio

Клонируйте официальный репозиторий OBS Studio:

```bash
git clone --recursive --branch 32.0.4 https://github.com/obsproject/obs-studio.git obs-filtered
cd obs-filtered
```

Для сборки OBS Studio также необходимы дополнительные зависимости.

При подготовке нового окружения рекомендуется использовать официальную документацию OBS Studio.

## 2. Применение патча

Скачайте файл:

`patches/obs-32.0.4-macos-capture.patch`

из репозитория OBS macOS Capture Filter.

Находясь в корневой директории исходников OBS Studio, выполните:

```bash
git apply --check /путь/к/obs-32.0.4-macos-capture.patch
git apply /путь/к/obs-32.0.4-macos-capture.patch
```

Первая команда проверяет возможность применения патча, не изменяя файлы.

Вторая команда применяет изменения.

Патч затрагивает три файла:

```text
plugins/mac-capture/mac-sck-common.h
plugins/mac-capture/mac-sck-common.m
plugins/mac-capture/mac-sck-video-capture.m
```

## 3. Настройка сборки

Независимая сборка модифицированного плагина успешно выполнена из чистой копии исходников OBS Studio 32.0.4 с использованием CMake и Xcode.

Следующий пример предполагает, что зависимости OBS Studio уже доступны локально:

```bash
cmake -S . -B build_macos -G Xcode \
  -DCMAKE_OSX_DEPLOYMENT_TARGET=12.0 \
  -DCMAKE_PREFIX_PATH="/путь/к/obs-deps;/путь/к/obs-deps-qt6" \
  -DVIRTUALCAM_DEVICE_UUID="$(uuidgen)" \
  -DVIRTUALCAM_SOURCE_UUID="$(uuidgen)" \
  -DVIRTUALCAM_SINK_UUID="$(uuidgen)"
```

Замените пути к зависимостям на фактические пути в вашем окружении.

### Особенность настройки Swift

При независимой проверке сборки первоначально возникала ошибка:

```text
CMake can not determine linker language for target: libobs-metal
```

Причина заключалась в том, что расширение виртуальной камеры завершало конфигурацию до вызова `enable_language(Swift)`: необходимые UUID не были заданы. Указание трёх корректных UUID устранило ошибку в проверенном окружении.

Параметр `CMAKE_OSX_DEPLOYMENT_TARGET=12.0` не означает, что совместимость модификации с macOS 12 подтверждена.

Для установки зависимостей и подготовки нового окружения используйте официальную документацию OBS Studio.

## 4. Сборка плагина

После настройки окружения выполните:

```bash
cmake --build build_macos --config Debug --target mac-capture -j "$(sysctl -n hw.ncpu)"
```

В существующей сборке автора плагин находится по пути:

```text
build_macos/plugins/mac-capture/Debug/mac-capture.plugin
```

Расположение собранного плагина может отличаться в зависимости от конфигурации.

## 5. Проверка работы

В окружении автора наблюдались следующие результаты:

| Функция | Результат |
|---|---|
| Исключение ChatGPT Classic из записи | Работает |
| Исключение AdGuard VPN из записи | Работает |
| Создание скриншота через `⌘ + Shift + 4` | Временное изменение фильтрации; после закрытия интерфейса обычный захват восстанавливается |
| Исключение Dock из записи | Не работает |

Список исключаемых приложений в текущей реализации прописан непосредственно в исходном коде.

## Важные замечания

- Проект является экспериментальной модификацией OBS Studio.
- Патч предназначен для OBS Studio 32.0.4.
- Применение патча и независимая компиляция `mac-capture` успешно проверены. Работа свежесобранного плагина в отдельном экземпляре OBS пока не проверялась.
- Наличие собранного плагина не гарантирует совместимость с другими установками OBS.
- Не рекомендуется заменять компоненты установленного OBS без резервной копии и возможности восстановления.
- Замена плагина и повторная подпись приложения могут повлиять на обновления, разрешения и работу отдельных компонентов OBS.
- Модификация не гарантирует полного скрытия конфиденциальной информации при записи экрана.

## Исходный проект

Модификация основана на [OBS Studio](https://github.com/obsproject/obs-studio).

OBS Studio разрабатывается OBS Project и участниками сообщества.

Данный репозиторий представляет собой независимый экспериментальный проект и не является официальной модификацией OBS Project.
