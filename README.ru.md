# OBS macOS Capture Filter

Экспериментальная модификация OBS Studio для macOS, позволяющая исключать выбранные приложения из записи экрана с помощью Apple ScreenCaptureKit.

Проект основан на исходном коде OBS Studio 32.0.4 и изменяет работу встроенного плагина `mac-capture`.

## Возможности

- Исключение окон ChatGPT Classic и AdGuard VPN из записи экрана.
- Сохранение видимости исключённых приложений на самом Mac.
- Временная заморозка изображения при использовании системного инструмента создания скриншотов (`⌘ + Shift + 4`).
- Работа на уровне нативного плагина OBS Studio.

## Как это работает

Модификация использует API ScreenCaptureKit и изменяет конфигурацию `SCContentFilter`, применяемого при захвате экрана.

Вместо записи всех доступных приложений фильтр исключает окна приложений, указанных в исходном коде по их Bundle ID.

Дополнительная логика отслеживает использование системного инструмента создания скриншотов macOS и временно приостанавливает обновление изображения в записи.

## Ограничения

- Список исключаемых приложений задаётся непосредственно в исходном коде.
- Dock продолжает отображаться в записи.
- При создании скриншота изображение временно замирает.
- Модификация проверялась на основе OBS Studio 32.0.4.
- Совместимость с другими версиями OBS Studio и macOS не подтверждена.

## Статус проекта

Экспериментальный проект.

Основная функция исключения приложений проверена на ChatGPT Classic и AdGuard VPN.

Проект не гарантирует полного скрытия всех системных элементов macOS или информации об исключённых приложениях.
