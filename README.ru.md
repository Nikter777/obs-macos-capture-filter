# OBS macOS Capture Filter

[English](README.md) | [Русский](README.ru.md)

> Экспериментальная модификация OBS Studio для macOS, ориентированная на конфиденциальность при записи экрана и использующая Apple ScreenCaptureKit.

**OBS macOS Capture Filter** — экспериментальный проект, изменяющий работу встроенного плагина `mac-capture` в OBS Studio для исключения определённых приложений из записи экрана.

Исключённые приложения продолжают отображаться на экране Mac, однако их окна не попадают в записываемое видео.

Дополнительно проект исследует возможность управления захватом экрана во время использования системного инструмента создания скриншотов macOS.

**Основано на OBS Studio 32.0.4.**

## Возможности

### Исключение приложений из записи

Модификация использует системный фреймворк Apple ScreenCaptureKit для исключения приложений из записи экрана по их Bundle ID.

Работа проверена со следующими приложениями:

| Приложение | Bundle ID | Статус |
|---|---|---|
| ChatGPT Classic | `com.openai.chat` | Работает |
| AdGuard VPN | `com.adguard.mac.vpn` | Работает |

Список исключаемых приложений в текущей реализации задаётся непосредственно в исходном коде.

### Обработка создания скриншотов

В проекте реализована экспериментальная обработка сочетания клавиш:

`Command + Shift + 4`

При активации системного инструмента выделения области экрана поведение захвата временно изменяется. Значки рабочего стола могут исчезать из записываемого изображения, но после закрытия интерфейса создания скриншота обычный захват восстанавливается.

Это позволяет не отображать процесс выделения области экрана обычным образом в записываемом видео.

### Интеграция с OBS Studio

Модификация реализована непосредственно во встроенном плагине `mac-capture` OBS Studio.

Для работы логики захвата не требуется отдельное приложение для записи экрана или внешний скрипт автоматизации.

## Как это работает

Для захвата содержимого экрана на macOS OBS Studio использует системный фреймворк Apple ScreenCaptureKit.

В рамках проекта изменена конфигурация `SCContentFilter`, благодаря чему из захватываемого изображения исключаются выбранные приложения.

Дополнительная логика отслеживает активность системного инструмента создания скриншотов и временно изменяет поведение захвата.

Патч затрагивает три файла исходного кода OBS Studio:

```text
plugins/mac-capture/mac-sck-common.h
plugins/mac-capture/mac-sck-common.m
plugins/mac-capture/mac-sck-video-capture.m
```

При разработке использовались:

- Objective-C и C
- Apple ScreenCaptureKit
- Core Graphics
- Системные API macOS
- CMake и Xcode
- Внутренние механизмы OBS Studio

## Проверенные результаты

В рабочем окружении автора получены следующие результаты:

| Функция | Результат |
|---|---|
| Исключение ChatGPT Classic из записи | Работает |
| Исключение AdGuard VPN из записи | Работает |
| Создание скриншота (`Command + Shift + 4`) | Временное изменение фильтрации; затем восстановление обычного захвата |
| Отображение macOS Dock | Поведение различается между проверками; надёжное исключение не подтверждено |

Результаты относятся к проверенному окружению и не гарантируют аналогичного поведения на других устройствах.

## Известные ограничения

Проект является экспериментальным и не предназначен для обеспечения полной конфиденциальности при записи экрана.

- **Отображение Dock:** поведение системного Dock различалось между проверками. Его исключение из записи не гарантируется.
- **Фиксированный список приложений:** изменение списка исключений требует редактирования исходного кода.
- **Создание скриншотов:** значки рабочего стола могут временно исчезать из захватываемого изображения. После закрытия интерфейса скриншота обычный захват восстанавливается.
- **Совместимость:** патч предназначен для OBS Studio 32.0.4. Работа с другими версиями не проверялась.
- **Системный интерфейс:** отдельные элементы macOS, уведомления, индикаторы приложений и конфиденциальные сведения могут оставаться видимыми.
- **Установка:** универсальный установщик не предоставляется.

Перед использованием модификации рекомендуется самостоятельно проверять результат записи.
